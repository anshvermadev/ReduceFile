# Contributing to ReduceFile 🤝

First off, thank you for considering contributing to **ReduceFile**! It's people like you that make open-source software such a great community to learn, inspire, and create.

## Where do I go from here?

If you've noticed a bug or have a feature request, please make sure to check the [Issues](../../issues) tab first to see if someone else has already created a similar issue or pull request.

If it doesn't exist, feel free to open a new one!

## Setting up your development environment 🛠️

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/ReduceFile.git
   ```
3. **Navigate to the directory**:
   ```bash
   cd ReduceFile
   ```
4. **Install dependencies**:
   ```bash
   npm install
   ```
5. **Start the development server**:
   ```bash
   npm run dev
   ```
   *This will start the Plasmo development server.*

### Loading the Extension in Developer Mode
1. Open Google Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** in the top right corner.
3. Click on **Load unpacked**.
4. Select the `build/chrome-mv3-dev` folder generated by the dev command.

## Pull Request Process 🚀

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface or instructions, if applicable.
3. Make sure your code matches the existing style and architecture (Tailwind CSS, React 19, Zustand).
4. Commit your changes with a descriptive commit message.
5. Push to your fork and submit a Pull Request!

## Code of Conduct

By participating in this project, you agree to abide by standard open-source community guidelines. Be respectful, be kind, and let's build something awesome together!
